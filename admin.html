How to Deploy on GitHub Pages

  1. Download all website files (index.html, products.html, about.html, contact.html, admin.html, css/, js/)
  2. Go to github.com and create a free account
  3. Click "New Repository" → name it haluex (lowercase)
  4. Upload all files to the repository
  5. Go to Settings → Pages → Source: main branch → Save
  6. Your site will be live at: yourusername.github.io/haluex
  7. Admin panel at: yourusername.github.io/haluex/admin.html

⚠️ Note: GitHub Pages is free and your site will be live in 2–5 minutes after upload.
